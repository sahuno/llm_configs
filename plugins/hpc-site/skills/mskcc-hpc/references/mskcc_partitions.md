- **Quick check before submitting**: `mcp__slurm__slurm_queue_info partition=cpushort` shows idle/mixed/allocated node counts. If cpushort is also saturated, `componc_cpu` is the next fallback (same hardware tier, longer time limit, allow-listed for greenbab).
